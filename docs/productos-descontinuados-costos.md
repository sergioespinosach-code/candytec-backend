# Costos de productos descontinuados

En **Mis productos → Productos descontinuados**, Gerencia puede editar la ficha de un producto dado de baja sin restaurarlo. La ficha permite vincular formulación y registrar peso, rendimiento, lámina, empaques y costos adicionales. Guardar la ficha no modifica existencias ni incorpora el producto al catálogo para pedidos nuevos.

El apartado también muestra nombres presentes en pedidos facturados que ya no tienen registro en el catálogo. **Crear ficha histórica** guarda un producto descontinuado con el nombre exacto de los pedidos, sin crear inventario. Los pedidos y movimientos históricos siguen intactos. Solo Gerencia puede crear o editar estas fichas; se auditan los cambios.

El estado de resultados utiliza el costo por presentación que se calcula desde estas fichas, con los precios promedio actuales de materias primas. Si un nombre vendido no coincide con una ficha completa, la utilidad queda pendiente y se indica el producto faltante. El costo actual es una estimación para ventas pasadas, no el costo histórico de la fecha de factura.
